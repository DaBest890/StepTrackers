## Android Project Setup

The repository-level Gradle configuration includes the `StepTracker` and `BallisticsCalculator` modules.

```bash
git clone https://github.com/maximowinfield/First_Touch_On_Mobile_Apps2024.git
cd First_Touch_On_Mobile_Apps2024
```

On Windows, list the available Gradle projects with:

```powershell
.\gradlew.bat projects
```

On macOS or Linux:

```bash
./gradlew projects
```

Individual Android modules can also be opened from the repository root in Android Studio.

## Repository Note

This repository is a multi-project learning archive rather than a single production application. Each directory represents a separate exercise or application at its own stage of development.
